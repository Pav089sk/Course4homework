# Проект функциональности для приложения для торговли

Проект реализует базовое ядро для интернет‑магазина (e‑commerce) с использованием ООП‑подхода. Код можно использовать как основу для разных интерфейсов: веб‑сайта, мобильного приложения, Telegram‑бота и т. д.

## Функционал

В рамках задания реализованы:

* **Класс `Product`** — описывает товар с атрибутами:
    * `name` — название;
    * `description` — описание;
    * `price` — цена;
    * `quantity` — количество в наличии.
* **Класс `Category`** — описывает категорию с атрибутами:
    * `name` — название;
    * `description` — описание;
    * `products` — список товаров категории.
* **Атрибуты класса `Category`**:
    * `category_count` — автоматически подсчитывает количество созданных категорий;
    * `product_count` — автоматически обновляет общее количество товаров во всех категориях.
* **Тестирование**:
    * проверка корректности инициализации объектов `Product` и `Category`;
    * контроль подсчёта количества категорий и товаров;
    * покрытие кода тестами > 75 %.
* **Дополнительное задание** : функция загрузки данных из JSON‑файла (`products.json`) с созданием объектов классов.

###  Строковое представление объектов

Реализованы магические методы `__str__` для удобного отображения объектов:

**Для класса `Product`:**
* формат вывода: «Название продукта, 80 руб. Остаток: 15 шт.»;
* используется для преобразования объекта `Product` в читаемую строку.

**Для класса `Category`:**
* формат вывода: «Название категории, количество продуктов: 200 шт.»;
* количество продуктов рассчитывается как сумма атрибутов `quantity` всех товаров в категории;
* оптимизирован геттер `@property products` — теперь использует `str(product)` для каждого товара.

### Сложение продуктов (`__add__`)

Реализован метод `__add__` в классе `Product` для расчёта общей стоимости товаров на складе:

* логика: цена × количество для каждого товара, затем суммирование результатов;
* пример: для товара `a` (цена 100 руб., количество 10) и товара `b` (цена 200 руб., количество 2) результат `a + b` равен $100 \times 10 + 200 \times 2 = 1400$;
* позволяет вычислять общую стоимость запасов для любых двух товаров.

Добавлены тесты для проверки:

* совместимости новых тестов с существующим набором — все предыдущие тесты выполняются без ошибок;
